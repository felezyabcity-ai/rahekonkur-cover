# سازنده حرفه‌ای کاور وردپرس و مقایسه اساتید (WordPress Cover & Teacher Comparison Generator)

یک وب‌اپلیکیشن فوق‌العاده مدرن، واکنش‌گرا و سریع برای ساخت کاورهای مقالات وردپرس، پوسترهای بیوگرافی و کاورهای مقایسه اساتید (VS) با خروجی فوق بهینه WebP برای بهترین نمره Core Web Vitals و سئو.

---

## 🌟 قابلیت‌های اصلی

1. **کاور مقایسه اساتید (Teacher Comparison / VS Duel):**
   - حالت ۲ استادی و ۳ استادی (۳ چهره در کنار هم با رتبه‌بندی سکویی).
   - جابه‌جایی آزادانه تمام المان‌ها (عنوان، زیرعنوان، مدال VS، فوتر، لوگو و کارت اساتید) با ماوس (Drag & Drop).
   - ایزوله‌سازی مختصات المان‌ها به تفکیک قالب تا تغییر یک قالب اثری روی بقیه نگذارد.
   - تنظیمات فوتر آکادمیک و برندینگ اختصاصی.

2. **کاور بیوگرافی اساتید (Teacher Bio):**
   - قاب‌های متنوع پرتره، هاله نوری و حذف رنگ پس‌زمینه (Chroma Key).
   - دودل‌های آکادمیک موضوعی (فیزیک، ریاضی، شیمی، زیست‌شناسی و عمومی).

3. **کاور مقالات وبلاگی وردپرس (Editorial & Guides):**
   - تیترهای برجسته با امکان هایلایت کلمات کلیدی (`<mark>`).
   - استایل‌های متنوع فونت‌های فارسی (وزیرمتن، لاله‌زار، کوفی و تاهما).
   - نشانگر تعداد سؤال و گزینه‌های تست کنکوری.

4. **تبدیل سریع و خروجی بهینه WebP:**
   - بهینه‌سازی خودکار تمام تصاویر آپلود شده به حداکثر عرض ۸۰۰ پیکسل و کیفیت ۰.۸ وب‌پی.
   - خروجی بسیار سبک (زیر ۵۰ کیلوبایت) با وضوح خیره‌کننده.
   - کپی مستقیم عکس در کلیپ‌بورد برای پیست آسان در ادیتور وردپرس (Gutenberg).
   - پشتیبان‌گیری خودکار در حافظه مرورگر با مدیریت سهمیه حافظه (`QuotaExceededError`).

## 🚀 راهنمای نصب و اجرا بر روی سیستم شما

### پیش‌نیازها
- **Node.js**: نسخه 18 یا بالاتر
- **npm** یا **pnpm** یا **yarn**

### مراحل راه‌اندازی سریع

1. **دانلود و استخراج فایل فشرده:**
   فایل `wordpress-cover-generator.zip` را استخراج کنید و وارد پوشه پروژه شوید:
   ```bash
   cd wordpress-cover-generator
   ```

2. **نصب وابستگی‌ها (Dependencies):**
   ```bash
   npm install
   ```

3. **اجرای سرور توسعه (Development Server):**
   ```bash
   npm run dev
   ```
   سپس در مرورگر خود به آدرس زیر بروید:
   ```
   http://localhost:3000
   ```

4. **ساخت نسخه نهایی برای پروداکشن (Build):**
   ```bash
   npm run build
   ```

## 🛠 فناوری‌های به‌کار رفته
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Lucide React Icons
- **Backend:** Node.js, Express (برای پراکسی API و سئو)
- **Canvas & Export:** HTML5 Canvas API, WebP compression
